# QuiStock — Backend

Backend do **QuiStock**, sistema de gerenciamento de estoque desenvolvido utilizando a arquitetura **MVC**.

## Tecnologias

* Java Web
* PostgreSQL

## Estrutura

O projeto utiliza o padrão **MVC (Model, View e Controller)** para organização do backend.

## Banco de Dados

Os scripts e queries do banco de dados são desenvolvidos e testados na branch:

`queries`

Nela são realizadas as criações das tabelas, inserções, consultas e demais operações relacionadas ao banco.
